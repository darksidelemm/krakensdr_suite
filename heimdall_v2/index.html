📡 Array Elements

Number of coherent channels in use. Changing it closes and reopens the RTL-SDR devices and runs a full recalibration (~30-60 s). Devices beyond the selected count are released on the USB bus for use by other programs. Selecting more channels than are physically attached fails and rolls back.
Hardware notes: KrakenSDR has 5 elements. KerberosSDR (4 elements, no noise-source switch) should be run with the --kerberos flag; a KerberosSDR modified with CKOVAL antenna switches with --kerberos_sw.

🧮 Forward Phase Compensation (S2P)

Forward Comp: OFF
VNA-measure each antenna chain (cable / filter / LNA) as a 2-port Touchstone .s2p file, then upload the files below (they are stored in the s2p_calibration/ folder on the receiver). Pick one file per channel. The forward-transmission S21 phase (and amplitude) is calibrated out relative to the reference channel at the tuned frequency — this corrects the components in front of the KrakenSDR that the noise-source calibration cannot see. Re-interpolated automatically when you change frequency.
